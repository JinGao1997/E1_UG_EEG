Offer-locked ERP component definitions — FRN & late positivity

Ultimatum Game EEG study (E1 sequential, E2 simultaneous) · offer-phase fairness analysis · prepared 2026-06-07

Reporting structure (agreed with W. Sommer). Two tiers are reported, in this order, for transparency: Preregistered analyses first (exactly as registered), then Exploratory analyses using the data-driven peak-based definitions below. Both tiers are extracted in a single pipeline pass and analysed with the same single-trial LMM amplitude approach.

2  FRN (fronto-central; Unfair − Fair)

Preregistered

ROI: F3, Fz, F4, FC1, FC2, Cz.   Search range: 200–300 ms. Window selection: peak detection across all conditions using a collapsed-localizer technique (Luck & Gaspelin, 2017) — the measurement window is centred (±25 ms) on the most-negative peak of the condition-collapsed grand average at the FRN ROI within 200–300 ms.

ExperimentCollapsed-localizer peak (200–300 ms)Resulting window (peak ±25 ms)
E1278 ms253–303 ms
E2218 ms193–243 ms

Sampling-grid note. Epochs are sampled at 500 Hz on an even-millisecond grid. The ±25 ms edges (odd ms) are rounded outward to the nearest sample, so the stated window equals the time points actually averaged: E1 252–304 ms, E2 192–244 ms. This is a numeric no-op (MNE already realizes the ±25 ms spec as exactly these samples).

Caveat for E2 (report transparently). In E2 the face and offer appear simultaneously, so the 200–300 ms range contains a large early visual negativity (peaking ~218 ms, ~−3.3 µV) that is most likely face-evoked rather than the feedback-related FRN. Applying the preregistered rule therefore places the E2 window on this early visual deflection; the genuine fronto-central FRN appears later (>300 ms), which motivates the exploratory window below. The preregistered E2 result is reported as-is, with this limitation noted.

Exploratory

ROI: Fz, FC1, FC2, Cz (medial fronto-central).   Search range: 250–350 ms. Window selection: most-negative peak of the emotion-collapsed Unfair − Fair difference wave at the FRN ROI, ±25 ms.

ExperimentDifference-wave peak (250–350 ms)Resulting window (peak ±25 ms)
E1334 ms310–360 ms
E2350 ms325–375 ms

Sampling-grid note. Rounded outward to the even-ms 500 Hz grid for analysis: E2 324–376 ms (E1 310–360 already on-grid).

FRN ROI rationale. The exploratory ROI drops F3 and F4 relative to the preregistered ROI. F3/F4 are more anterior/frontal than the electrodes typically emphasised for the FRN; they had originally been included to compensate for FCz being unavailable (FCz was the recording ground electrode). However, in the Cartool maps F3/F4 emphasise an atypical right-frontal lateralised negativity that may bias the FRN interpretation, so the exploratory analysis focuses on the medial fronto-central electrodes (Fz, FC1, FC2, Cz).

3  Late positivity — preregistered LPP / exploratory P3

Preregistered (LPP)

ROI: Pz, Cz, C1, C2, CP1, CP2.   Window: 400–600 ms (fixed; both experiments; Abdel Rahman, 2011). Mean amplitude over the fixed window.

Exploratory (P3)

ROI: Cz, CPz, Pz, CP1, CP2 (centro-parietal).   Search range: 300–700 ms. Window selection: most-positive peak of the condition-collapsed grand average at the P3 ROI.

P3 ROI rationale. The exploratory P3 ROI overlaps the preregistered LPP ROI but is adjusted toward the typical centro-parietal P3 distribution: relative to the preregistered ROI (Pz, Cz, C1, C2, CP1, CP2) it drops C1 and C2 and adds CPz. The window (490–590 ms) is close to the preregistered 400–600 ms LPP window but targets the later centro-parietal positivity seen in the present data.

4  Window-derivation method (both tiers)

All windows are set by a peak-based rule within a predefined search interval, then mean amplitude is measured in that window (per component × ROI) and entered into the single-trial LMM amplitude analyses. The localizers differ by tier:

  • Preregistered FRN — collapsed localizer on the condition-collapsed grand average (Luck & Gaspelin, 2017).
  • Exploratory FRN — peak of the Unfair − Fair difference wave (targets the fairness effect).
  • Exploratory P3 — peak of the condition-collapsed grand average.
  • Preregistered LPP uses a fixed 400–600 ms window (no peak step).

Peak detection used the baseline-corrected (Standard) grand averages; half-window = ±25 ms. This proposal is broadly consistent with the Cartool topographic segmentation, which helped separate the earlier fronto-central activity from the later centro-parietal positivity. The exploratory FRN windows are later than the preregistered 200–300 ms range but fall within the range summarised by Liang et al. (2026).
